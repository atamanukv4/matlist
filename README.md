# Матлист

Рабочий лист в духе Mathcad 15 для телефона: формулы с шаблонной клавиатурой, определения `:=` и вывод `=`, функции, ранжированные переменные, матрицы, системы уравнений, Given/Find, Odesolve, графики с жестами и подложкой, открытие и сохранение `.xmcd`.

## Установка на телефон

Последний APK — в разделе **Releases** этого репозитория. Скачайте `Matlist-*.apk` на телефон, откройте его и разрешите установку из этого источника. Новые сборки ставятся поверх старых: все они подписаны одним тестовым ключом.

## Устройство

| Папка | Что внутри |
| --- | --- |
| `src/engine.js` | разбор формул (LaTeX из MathLive), вычисление с семантикой Mathcad, решатели |
| `src/xmcd.js`, `src/xmcd_template.js` | чтение и запись `.xmcd` (схема Mathcad 15 `math30.xsd`) |
| `src/plot.js` | графики: оси, легенда, подложка, жесты |
| `src/app.js`, `src/index.html`, `src/style.css` | интерфейс листа и клавиатуры |
| `android/` | обёртка WebView: assets, выбор и сохранение файлов, «Открыть с помощью» |
| `test/` | тесты ядра, решателей, `.xmcd` и сценарии в браузере |

## Сборка

```
npm ci
node build.js          # dist/web — для браузера, dist/apk-assets — для Android
./test/run_all.sh      # все проверки (нужны Python и Playwright)
```

APK собирает GitHub Actions (`.github/workflows/build.yml`) при каждом push в `main`.

Тестовый ключ подписи `android/matlist-test.keystore` лежит в репозитории намеренно, чтобы обновления ставились поверх. Для публикации в магазине нужен свой ключ, хранящийся вне репозитория.
